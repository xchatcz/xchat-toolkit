XChat Toolkit

Kolekce vylepšení pro www.xchat.cz

Funkce

Jednotlivé funkce odpovídají původním userscriptům. Můžete je libovolně vypínat.

    Ikony rozšíření

    Logo XChat Toolkitu – velké oranžové „X" a malé modré „t".

    Instalace a nastavení prohlížeče

    1. V Chrome / Edge / Brave otevřete chrome://extensions.
    2. Zapněte vpravo nahoře Vývojářský režim (Developer mode).
    3. Klikněte na Načíst rozbalené (Load unpacked) a vyberte složku dist/ projektu.
    4. Pro pohodlnější přístup ikonu připněte kliknutím na symbol puzzle a špendlík.
    5. Pokud používáte přísné blokátory cookies, povolte stránkám xchat.cz a scripts.xchat.cz cookies třetí strany, aby fungovaly všechny API volání.
    6. Po aktualizaci rozšíření je vhodné obnovit otevřené záložky XChatu.
